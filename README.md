# ZeeTummyLab

A responsive Nigerian food ordering website built with React and Vite. It includes a browsable food menu, cart and checkout flow, an order-status timeline, an About Us page, and a browser-local admin demo.

## Getting started

Requirements: Node.js and npm.

```sh
npm install
npm run dev
```

## Available scripts

- `npm run dev` — start the local development server
- `npm run build` — create a production build in `dist`
- `npm run preview` — preview the production build locally
- `npm run lint` — run ESLint

## Demo limitations

- The admin dashboard and orders use this browser's local storage. There is no staff authentication, shared backend, payment processing, or live order service. Do not use the demo dashboard for real customer or business operations.
- The checkout confirmation is for demonstration only and does not send an order to a restaurant.
- Restaurant location, opening hours, food-safety practices, and restaurant photographs are sample/illustrative content. Replace them with verified business details and original assets before publishing for real customers.
- Menu photography is loaded from Unsplash.
